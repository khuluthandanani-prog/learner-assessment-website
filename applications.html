Tutor applications:

Open the documents, check them, then accept or reject. Learners are accepted automatically 24 hours after they apply, unless you accept or reject them first. Tutor applications always need you to accept them. Fix a spelling with Edit location (learners) or Edit schools (tutors). A tutor can teach at any number of schools, and each school has its own subjects. Learners only see the notes, videos and assessments for a subject the tutor teaches at the learner's school, so the school names must match exactly.

Parent verification: open Parent selfie, check that it shows a real adult face, then press Verify parent. A parent can only register for parent access after you verify. Press Reject parent to refuse (this also removes any parent login that exists).

View only. Only the secret admin can accept, reject or edit applications.
