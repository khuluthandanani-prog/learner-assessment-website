Open or close applications

When an application type is closed, people who press Apply for it see "Applications are currently closed." Only the admin can change this.

Learner applications:
Tutor applications:

Open the documents, check them, then accept or reject. Learners are accepted automatically 24 hours after they apply, unless you accept or reject them first. Tutor applications always need you to accept them. Use Edit all details to change the grade, name, ID number, cell, parent name, location or subjects of a learner, or the name, email, cell, ID number and location of a tutor. A tutor can teach at any number of schools, and each school has its own subjects: change those with Edit schools. Use Reset password to give a registered tutor a new password. Learners only see the notes, videos and assessments for a subject the tutor teaches at the learner's school, so the school names must match exactly.

Parent verification: open Parent selfie, check that it shows a real adult face, then press Verify parent. A parent can only register for parent access after you verify. Press Reject parent to refuse (this also removes any parent login that exists).

View only. Only the secret admin can accept, reject or edit applications.
